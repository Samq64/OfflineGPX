This is a GPX viewer and recorder for Android written in Kotlin and Compose with no INTERNET permission. Vector based `.map` files are imported manually by the user. Keep the app lean in terms of libraries and permissions. Keep code comments concise. Currently no backwards compatibility is necessary, just flag user-facing breaking changes in the output summary and commit messages. When an emulator is available specify it every time to avoid accidentally touching physical devices. Don't worry about cleaning up its state. Resetting the emulator's app data is also fine.
